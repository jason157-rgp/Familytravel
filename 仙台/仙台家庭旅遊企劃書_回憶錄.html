仙台七日

龜山下智久、桃園星野結衣和小魚乾的七天六夜——青葉通的櫸木、秋保的紅葉，和第一天就買下的那頂飛行員帽。

這是小魚乾第一次去東北。前四天住在仙台站前，跟著交流團去了南三陸、看了水族館；後三天租車上山，到秋保溫泉住兩晚。正好遇上楓紅，翻照片時才發現，這趟最多的顏色是紅色——八幡宮的楓葉、秋保大滝兩旁的山，和全家事先說好要穿的紅毛衣。

1

長町的第一晚

2026.10.30 FRI · 桃園 → 仙台機場 → 仙台站 → 長町 → 仙台站前
  • 08:58

    桃園機場的貴賓室

    爸爸帶小魚乾進貴賓室，坐在大大的單人沙發上吃點心、到處摸摸看。

  • 10:15

    BR118，從桃園出發

    長榮的報到與登機都走優先通道。機上的鄰座對他很友善。

  • 14:25

    落地仙台

    機場裡一張「WELCOME TOHOKU JAPAN」的東北地圖迎接我們。日本入境有帶嬰兒旅客專用的櫃檯；行李掛著 Priority 標籤，出關時已經有人從轉盤上拿下來排好。

  • 15:29

    仙台空港アクセス線（仙台機場線）

    他跪在藍色座椅上看窗外。照著事先查好的無樓梯路線，推著嬰兒車一路到仙台站，一階樓梯都沒有走。

  • 16:13

    仙台國際飯店

    住進站前的飯店，他一進房間就拿起床頭的電話「講」個不停。

  • 17:38

    LaLa Garden 長町

    搭地下鐵到長町。在アカチャンホンポ（阿卡將本舖）買到一個可愛的揹包，和一頂有護耳的飛行員帽——這頂帽子後來幾天一直跟著出門。

  • 18:59

    第一杯麒麟

    晚餐就在商場裡：松露培根蛋麵、焗烤雞排，配這趟的第一杯麒麟生啤。逛著逛著，他在嬰兒車裡睡著了。

2

八木山的動物們

2026.10.31 SAT · 仙台朝市 → 八木山動物公園 → 仙台站 S-PAL
  • 09:21

    爸爸的太陽眼鏡

    出門前，他在房間裡拿起爸爸的太陽眼鏡，戴不上去就舉在眼前。

  • 10:03

    仙台朝市

    往動物園的路上經過仙台朝市，買了一袋橘子。

  • 10:40

    八木山動物公園フジサキの杜（八木山動物公園）

    園裡看了犀牛、紅鶴，最後坐在爸爸肩上看猩猩。離開前，又在八木山的招牌前拍了一張。

  • 11:45

    園內的午餐

    漢堡排盤上的白飯捏成小熊，另一盤是番茄義大利麵；他坐在露台的木桌前，等大人把飯切小。

  • 12:36

    反射鏡裡的三個人

    轉角一面圓形反射鏡，背後是紅葉和藍天，剛好把全家裝進去。

  • 12:55

    草地與樹樁

    在草地上跑來跑去，找到一個樹樁就坐下來休息，旁邊還有一座企鵝雕像要摸。

  • 14:49

    門口的動物雕塑

    出口廣場上有幾座動物造型的大雕塑：長頸鹿、大象，還有一隻黃色的獅子。他在每個洞裡鑽進鑽出，全家輪流進去拍。

  • 15:09

    回程的地下鐵

    一上車就在嬰兒車裡睡著了。

  • 17:06

    伊達の牛たん本舗（伊達牛舌本舖）

    S-PAL 地下的牛舌定食，厚切牛舌配麥飯和牛尾湯；小魚乾有自己的兒童套餐。

3

葡萄、海風，和一條金色的魚

2026.11.01 SUN · 青葉通 → JR 水果園仙台荒濱 → 荒濱小學 → 南三陸 → 仙台
  • 08:22

    青葉通的櫸木大道

    早上沿著櫸木行道樹散步，他牽著媽媽的手，自己走過一整條街。

  • 09:56

    JR フルーツパーク仙台あらはま（JR 水果園仙台荒濱）

    仙台辯護士會交流團的第一站。葡萄棚下，大人把他抱高去摸一串串葡萄，媽媽也伸手摘了一串；草地上和草莓頭、葡萄身的吉祥物賽跑。

  • 10:41

    震災遺構 仙台市立荒浜小学校（震災遺跡 仙台市立荒濱小學）

    311 海嘯後保留下來的校舍。他在紀念碑前站好，又對著展示櫃的鏡子做鬼臉。

  • 11:13

    頂樓的風

    爬上通往頂樓的鐵梯，坐在鐵網邊看外面的田和海，門上貼著「強風注意」。

  • 13:03

    南三陸ホテル観洋（南三陸觀洋飯店）

    面海的餐廳吃午餐，兒童餐盤上插著一面小國旗。

  • 14:04

    一條比他還大的魚

    飯店大廳有一隻金色的鯛魚道具，寫著「目指鯛」，他抱起來就不放。

  • 14:27

    南三陸的中橋

    走過木造的中橋，對岸是紅色鋼骨的防災對策廳舍。商店街旁有一隻巨大的兔子雕塑，他爬過去坐在兔子旁邊。

  • 15:23

    南三陸さんさん商店街（南三陸燦燦商店街）

    媽媽買了一個點心，邊走邊吃。

  • 16:03

    「台湾の皆さんありがとう」（台灣的大家，謝謝你們）

    回程前經過一塊石碑，刻著對台灣的感謝。

  • 18:25

    Cross B Plus 歡迎會

    晚上的歡迎會，氣球師傅幫他做了一把藍色的氣球劍，他拿著揮了一整晚。

4

父子兩人的水族館

2026.11.02 MON · 仙石線 → 仙台海洋森林水族館 → 仙台大都會大飯店 → 友都八喜
  • 08:43

    媽媽去交流會

    這天媽媽參加交流會，爸爸帶小魚乾出門。

  • 10:37

    JR 仙石線

    一上電車就在嬰兒車裡睡著了。到了中野榮，爸爸推著他慢慢走去水族館，讓他多睡一點。

  • 11:18

    仙台うみの杜水族館（仙台海洋森林水族館）

    大水槽前父子兩人戴著口罩自拍，背後是鯊魚和整群沙丁魚。坐下來畫了一張著色紙，又鑽進展示區的圓洞裡探頭，還和大海獅一起拍了合照。

  • 12:40

    海龜

    坐在海龜水槽前的台階上，海龜就從他背後游過去。

  • 12:52

    頒獎台

    在企鵝區站上寫著「1」的台子。

  • 13:12

    海豚造型的午餐

    咖哩飯的白飯做成海豚的樣子，另一碗是拉麵。

  • 13:57

    海豚表演

    坐在看台上看海豚跳，爸爸抱著他一起看。

  • 17:59

    十週年紀念晚宴

    晚上在仙台大都會大飯店的紀念晚宴，全家和吉祥物合照；他抱著一本紅色的「六法」抱枕走來走去。

  • 20:57

    ヨドバシカメラ（友都八喜）

    晚宴後去友都八喜買東西。

5

戴上飛行員帽

2026.11.03 TUE · 文化之日 · 仙台站前取車 → 大崎八幡宮 → 安曇野 → 秋保溫泉 佐勘
  • 07:28

    借穿大人的鞋

    一早在房門口，先穿上媽媽的高跟鞋，再換爸爸的拖鞋。

  • 11:45

    大崎八幡宮

    國寶社殿前的楓葉正紅。全家照計畫穿上紅毛衣，在拜殿前合照，也抽了籤。

  • 13:24

    飛行員帽和三角錐

    到了午餐的店門口，他戴著第一天在阿卡將買的飛行員帽，一個人跟三角錐玩了起來。

  • 13:38

    駕駛座

    爬進租來的車，握著方向盤不肯下來。

  • 13:57

    SOBA to GALETTE あずみの（蕎麥與法式薄餅 安曇野）

    仙台的律師推薦的店：天婦羅蕎麥麵和蕎麥粉做的法式薄餅。

  • 15:20

    伝承千年の宿 佐勘（傳承千年之宿 佐勘）

    大廳一整排金色屏風，房間是寬敞的榻榻米。

  • 16:51

    換上浴衣

    全家換上浴衣，對著房門的鏡子自拍。

  • 18:33

    房裡的會席

    一道一道送進房間：八寸、生魚片、鮭魚卵飯、竹筒裡烤的魚。

  • 19:35

    先睡了

    吃到一半，他抱著布偶在嬰兒床裡睡著了。

6

秋保紅了

2026.11.04 WED · 佐勘 → 秋保大滝 → 秋保神社 → 秋保・里中心 → 磊々峡
  • 07:30

    穿著半纏吃早餐

    換上小小的半纏（日式短外套），坐在兒童椅上吃早餐。

  • 08:48

    大廳的全家福

    全家穿著浴衣，在挑高的大廳拍了一張。

  • 11:05

    秋保大滝（秋保大瀑布）

    三個人照計畫穿著紅毛衣，在「秋保大滝」的牌子前自拍。往下走就看到瀑布，兩旁山壁一片紅黃。

  • 11:27

    落葉的山路

    戴著熊耳帽，自己走在鋪滿落葉的山路上，偶爾回頭看大人有沒有跟上。

  • 12:08

    秋保神社

    路上看到，媽媽很想去就臨時停了下來。她在收集御朱印，這趟收了好幾個。白色的旗幟一路排到拜殿。

  • 13:08

    秋保・里センター（秋保・里中心）

    天花板掛滿彩色的和紙燈籠。

  • 13:28

    Cafe HACHI

    紅白格子桌布上用蠟筆畫著色紙。午餐是兒童盤、漢堡排義大利麵和仙台牛炒麵。

  • 17:32

    磊々峡（磊磊峽）的點燈

    傍晚沿著峽谷步道看點燈，楓葉在燈下變成整片橘紅。

  • 18:42

    第二晚的晚餐

    房裡的晚餐有牛舌和壽喜燒。

7

霧裡的早晨

2026.11.05 THU · 佐勘 → 金蛇水神社 → 仙台機場 → 桃園
  • 08:34

    窗外起霧

    最後一個早上，窗外的山谷全是霧。

  • 09:34

    一圈白鬍子

    天氣太乾，嘴邊破了皮，塗上一圈藥膏，看起來像長了白鬍子。

  • 09:55

    窗前的全家福

    穿著浴衣在窗邊拍了一整串，背後是霧裡的山。他一下比 YA、一下揮手。

  • 12:38

    金蛇水神社

    下著雨，撐著藍色的傘，牽著媽媽一階一階爬上石階；拜殿旁有一整面彩色和傘。

  • 14:37

    仙台空港（仙台機場）

    坐在嬰兒車裡，等著上飛機。

  • 15:03

    寿松庵（壽松庵）

    用航空公司給的餐券，吃了生魚片和最後一份牛舌。

  • 15:56

    BR117，回家

    商務艙裡全家自拍。他和媽媽一起看螢幕、靠在媽媽身上睡了一下，醒來後自己翻繪本，窗外是雲海。

  • 19:13

    回到桃園

    落地桃園。走出航廈，他堅持自己推行李箱。
